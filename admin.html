系統維護與修復

database_sync

【進階】資料庫狀態一鍵轉換工具 (Database Standardization)

此工具用於一次性修復歷史遺留的中文/舊式狀態資訊。將 ON/OFF、待處理、已確認 等雜亂術語，全面自動化轉換為標準英文字典檔 (pending, confirmed, completed, available...)。
[重要提示] 執行前請務必確保上方已完成備份下載。

group_work

【進階】會員資料 Doc ID 遷移工具 (Member Migration)

將舊式隨機 Doc ID 的會員文件，整合遷移至以手機號碼為 Doc ID 的標準格式。
使用 merge 策略合併資料，確保 7-11、全家、宅配等物流資訊不會遺失。
[重要提示] 遷移完成後，舊的隨機 ID 文件將被刪除。請先備份。
